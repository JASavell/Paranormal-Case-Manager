Paranormal Investigation Case Manager by Josh Savell.

Welcome to Paranormal Investigation Case Manager, a centralized software solution designed for investigators who catalog the unexplained, document the uncanny, and bring order to the chaos of the unknown.

This application helps you manage cases from first contact to final report, ensuring that no whisper, shadow, or EVP is ever lost to time.

You can see what we do at https://maps-paranormal.com



Core Features
---------------------------------------------------------------------
Client Management

Organize and maintain detailed client profiles, including contact 
information, case history, and related investigations. Each client
 acts as a hub for all associated paranormal activity and evidence.

---------------------------------------------------------------------
Phenomenon Logging

Record paranormal events with structured entries such as:

Date and time of occurrence

Location 

Type of phenomenon (apparition, audio anomaly, EMF spike, etc.)

Investigator observations and conclusions

These logs create a chronological narrative of each case.

-------------------------------------------------------------------

Evidence Organization

Manage and categorize investigative media with ease:

Audio: EVP recordings and ambient sound captures

Video: Static camera footage, walkthrough recordings, and thermal captures

Images: Photographs, infrared images, screenshots, and still frames

All evidence is linked directly to its corresponding case.

-------------------------------------------------------------------

Notes and Attachments

Store free-form notes for theories, research, and observations. 
Notes support image attachments, allowing annotated photos, diagrams,
or reference material to live alongside written analysis.

-------------------------------------------------------------------

Report Writing and Export

Compile professional investigation reports using the built-in report 
editor. Reports can be exported in:

PDF format for official documentation and sharing

Plain text format for archival, editing, or external processing

This ensures compatibility with both modern and legacy workflows.

--------------------------------------------------------------------

Task and To-Do Management

Track investigative tasks with an integrated to-do list:

Assign priorities

Set due dates

Schedule reminders

Perfect for managing equipment prep, follow-ups, and post-investigation analysis.

---------------------------------------------------------------------

Event Planning and Calendar Sync

Plan investigations, client meetings, and review sessions with event scheduling 
tools that synchronize directly with Google Calendar, keeping your paranormal 
work aligned with the rest of your life.
